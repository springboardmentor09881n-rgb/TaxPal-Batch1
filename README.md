# TaxPal

TaxPal is a full-stack personal finance and tax estimation application designed for freelancers and gig workers. It helps users manage their income and expenses, organize transactions, set budgets, estimate taxes, and generate financial reports.

## Features

- Secure user registration and login
- Income and expense tracking
- Transaction categorization
- Monthly budget management
- Spending and budget insights
- Regional tax estimation
- Quarterly tax tracking
- Monthly and quarterly financial summaries
- PDF and CSV report export

## Technology Stack

### Frontend
- Angular
- TypeScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- Users
- Transactions
- Budgets
- Tax Estimates
- Reports

## Main Modules

- **Income & Expense Management** — Record and manage financial transactions.
- **Categorization & Budgeting** — Organize transactions and manage spending limits.
- **Tax Estimation** — Calculate estimated taxes based on applicable tax slabs and region.
- **Reporting & Export** — Generate financial summaries and downloadable reports.
